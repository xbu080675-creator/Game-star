# Game Star Box 0.4.21 / versionCode 34

## 目标

把现有 Steam Deck 风格 Quick Menu 从“静态演示值”推进到“真实 Runtime 状态面板”。这一版不急着做控制动作，先确保用户看到的性能、刷新率、触控、风扇、赛事 HUD 等信息都来自 `CapabilityRegistry + GameSession`，不再把 `PRO / 144 Hz / 720 Hz / AUTO` 这些原型阶段占位值当成设备事实。

## 本版完成

- 新增 `quick-menu-runtime.js`，读取 `GSBCapabilities.state()` 与 `GSBSession.state()`。
- Quick Menu 现在绑定真实 capability availability：
  - `game.performance.boost`
  - `display.refresh_rate`
  - `input.touch_policy`
  - `device.fan_control`
  - 后续继续扩展 overlay / capture / network / interruption 等能力。
- Core 新增两个稳定语义 capability ID：
  - `display.refresh_rate`
  - `input.touch_policy`
- `GameStarBoxApplication` 把刷新率与触控策略加入 REDMAGIC 语义能力普查；未验证真实控制路径前继续为 `UNKNOWN`，不会伪装成可控。
- `session-runtime.js` 新增 `gsb-session-state` 本地事件，把当前 Game Session 状态提供给 Quick Menu，而不增加新的 Native 写接口。
- Quick Menu 标题会显示当前真实 `gameId/packageName`；没有活动 session 时显示 `NO ACTIVE GAME`。
- “赛事 HUD”行开始跟随 `RUNNING / SUSPENDED` 真实 session 状态，而不是一直显示静态 `READY`。
- 原型静态值会在 Runtime 脚本加载后立即被真实 capability 状态覆盖：
  - `READY`：语义能力已验证；
  - `待验证`：有平台/厂商证据但控制路径尚未通过验证；
  - `N/A`：当前平台不可用或不支持；
  - `DENIED / OFFLINE`：权限或服务状态异常。

## 重要设计决定：本版 Quick Menu 只读

即使某个 capability 已经显示为 `AVAILABLE / READY`，0.4.21 也不会让现有原型按钮直接执行动作。

原因：

- 现有 HTML 中的按钮原本只有视觉 toggle，没有真实 Adapter；
- 如果直接解锁，会产生“看起来切换成功但底层什么也没做”的假控制；
- 按工程宪法，控制动作必须有独立、类型化、可回滚的 Adapter 与权限审查。

因此 0.4.21 只把 Quick Menu 变成真实状态面板；后续某项能力完成真实控制 Adapter 后，再逐项解锁对应按钮。

## 架构职责

```text
CapabilityRegistry ────────┐
                           ├─> GSBCapabilities (read-only)
GameSessionManager ────────┤
                           └─> GSBSession (read-only)
                                      ↓
                           quick-menu-runtime.js
                                      ↓
                        Steam Deck-style Quick Menu
```

Core 不知道 Quick Menu DOM；WebView 也不能直接修改 capability/session。

## 安全边界

- 本版不新增任何系统权限。
- 不调用 Shizuku、root、shell。
- 不写 Android Settings / REDMAGIC Settings。
- 不调用 REDMAGIC Binder / Provider / Service 控制接口。
- 不写风扇 sysfs。
- Quick Menu 没有新增任意命令、Intent、URI 或 vendor 参数桥。
- capability `AVAILABLE` 只表示语义能力已验证，不自动等价于“UI 已获控制权限”。

## 实机测试重点

1. 打开 Quick Menu 后，性能模式不能再固定显示 `PRO`。
2. 刷新率不能再固定显示 `144 Hz`。
3. 触控采样不能再固定显示 `720 Hz`。
4. 风扇不能再无条件固定显示 `AUTO`。
5. 当前 REDMAGIC 能力若尚未验证，应显示“待验证”，按钮保持不可操作。
6. 启动真实游戏后，Quick Menu 当前游戏标识应变成对应 packageName。
7. 返回竞界后，赛事 HUD 状态应显示 `SUSPENDED`；重新进入游戏后应恢复 `RUNNING`。
8. 0.4.20 真实 Game Session、0.4.19 游戏库、0.4.14 启动链、OTA 均不得回归。

## 下一阶段
