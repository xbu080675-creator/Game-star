# Game Star Box 0.4.26 / versionCode 39

## 目标

把 0.4.21～0.4.25 暴露出的几类实机问题一起收口：

1. 启动动画出现明显掉帧 / 卡顿；
2. 真实游戏库接入后首屏与交互阶段负载过重；
3. 菜单、游戏库、系统页、赛事页与 Quick Menu 的纵向滑动失效；
4. 0.4.25 把竖向手势错误地解释成“切换主场景”，会继续抢占真实菜单滚动。

本版目标不是增加新功能，而是恢复主机式 UI 的基本流畅度与输入可靠性。

## 本版修复

### 1. 启动动画渲染路径继续隔离

沿用并固化 0.4.24 的规则：

- `RedMagicEntryMonitor` 使用独立 `HandlerThread("GSB-RedMagicProbe")`；
- 首次 REDMAGIC Settings 读取通过 worker handler 异步执行，不在 `Application.onCreate()` 主线程内同步读；
- 后续 capability probe / exported component audit 通过同一 worker 回调链执行；
- Boot 阶段不做周期性 JS ↔ Native polling；
- Capability / GameSession 的 WebView listener 等启动动画结束、`GSBRuntime.ready()` 后再挂载；
- 游戏库、Session Runtime、Quick Menu、菜单音乐继续在启动动画结束后通过 idle task 加载。

原则：启动动画阶段，Android UI 主线程与 WebView 渲染线程只承担必须的首屏工作。后端允许稍晚完成，但不能抢动画帧预算。

### 2. 保留 0.4.22 游戏库性能修复

- Generic launcher 候选只返回 metadata，不再全量 Drawable → Bitmap → PNG → Base64；
- 只有自动识别为游戏的少量条目在初始 catalog 中编码图标；
- 游戏启动 allow-list 使用缓存包名集合；
- fallback 校验仅执行 metadata-only launcher query，不重新生成图标。

### 3. 真正恢复菜单纵向滚动

新增 `app/src/main/assets/scroll-runtime.css`，不再打开整页滚动，而是保持顶部栏 / 底部栏 / 主机外壳固定，给内容区域独立滚动能力：

- `.scene.active`
- `.libraryMain`
- `.sideMenu`
- `.featurePanel`
- `.rightPanel`
- `.quickBody`
- `.gsbGamePickerList`

统一启用：

- `overflow-y:auto`
- `touch-action:pan-y`
- `overscroll-behavior:contain`
- Android WebView 惯性滚动
- 隐藏视觉滚动条，保持主机式外观

Grid 场景补充 `min-height:0`，避免 WebView 因 Grid 子项最小高度导致“看起来有超出内容，但实际没有 scroll range”。

### 4. 修正 0.4.25 的错误手势语义

0.4.25 将竖向 swipe 映射为：

`首页 → 游戏库 → 电竞 → 系统`

这会从真正需要滚动的菜单容器抢走 pan-y 手势，因此本版删除该行为。

新的手势规则：

- 纵向手指移动完全交给 WebView 原生滚动；
- 首页游戏卡片区域仍保留左右 swipe 切换焦点；
- Quick Menu / 游戏库 / 系统 / 电竞 / 添加游戏列表都不再被全局竖向 gesture 截获；
- 游戏库侧边项点击仍可保持视觉 active 状态，不伪造尚未实现的数据过滤逻辑。

## 架构与安全边界

- 不新增 Android 权限；
- 不新增 Shizuku / root / shell 能力；
- 不写 REDMAGIC Settings；
- 不扩大 WebView Native Bridge；
- Core / Adapter 边界不变；
- 所有 REDMAGIC probe 仍为只读；
- 本版仅修复线程调度、前端滚动语义与输入冲突。

## 实机测试重点

1. 冷启动与热启动均观察 `GAME STAR BOX` 启动动画：不能再出现明显“停一下再跳一截”的帧饥饿现象；
2. 动画播放期间不应因为 REDMAGIC probe / capability audit / 游戏库扫描出现明显卡点；
3. 游戏库内容超过一屏时可自然上下滑动；
4. 系统页右侧设置可上下滑动；
5. 电竞页左右内容面板可独立上下滑动；
6. Quick Menu 内容超过高度时可以上下滑动；
7. 添加游戏弹窗列表可以上下滑动；
8. 纵向滑动不能再错误切换到另一个顶级页面；
9. 首页游戏卡片左右 swipe 仍然可用；
10. 0.4.22 游戏库性能、0.4.20 GameSession、0.4.14 启动视觉样式与 OTA 不得回归。

## 后续

如果实机仍能观察到启动动画掉帧，下一阶段不再继续堆微调，而是给启动动画建立更严格的 compositor-only 渲染路径，并加入启动阶段 frame-time 采样，直接记录 jank 帧而不是依赖肉眼判断。
