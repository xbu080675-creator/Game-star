# Game Star Box 0.4.17 / versionCode 30

## 目标

进入 REDMAGIC P0 能力普查阶段，同时保持 0.4.16 Boot Runtime 和 0.4.14 启动视觉基线不动。

## 本版完成

- Core 新增稳定语义能力 ID：网络加速、性能增强、内存清理、通知屏蔽，以及 FPS 监控、准星、风扇、充电分离、肩键映射、录屏。
- 新增只读 `RedMagicCapabilityProbe`，探测 `cn.nubia.gamelauncher`、`cn.nubia.gameassist`、已知游戏 Settings 是否暴露，以及两个已知风扇 sysfs 节点是否存在。
- 新增 `RedMagicCapabilityProbeSnapshot`，把探测证据与实际控制能力分离。
- `GameStarBoxApplication` 将平台证据写入 `CapabilityRegistry`，但对应语义控制能力继续保持 `UNKNOWN`，直到真实调用路径、权限、回滚和实机验证全部完成。
- 增加 `[GSB-RM] survey ...` 稳定日志，便于红魔 9 Pro+ 实机收集能力证据。

## 安全边界

本版没有新增任何控制动作：不写 Settings、不调用 Shizuku、不执行 shell、不写 sysfs、不启动或注入红魔 Game Space/Game Assist，也不扩大 OTA Privileged Adapter。

## 实机重点

在红魔 9 Pro+ 上确认日志中的：

- `gameSpace=true/false`
- `gameAssist=true/false`
- `settings=true/false`
- `fanEnable=true/false`
- `fanSpeed=true/false`

这些结果只决定下一轮调查路径，不代表能力已经可控。

## 下一阶段

优先审计 `game.performance.boost` 和 `game.interruption_shield` 的厂商原生控制入口；若存在稳定 Binder/Provider/Intent/Settings 接口，才进入独立控制 Adapter 设计。风扇、充电分离、肩键等 Game Tools 后续逐项进入 Quick Menu capability。
