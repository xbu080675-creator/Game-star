# Game Star Box 0.4.27 / versionCode 40

## 版本目标

0.4.27 将首次启动升级为真正的 **Hardware Awakening**：用户亲手唤醒左右肩键控制模块，同时后台完成第一次进入竞界所需的阻塞准备；只有硬件仪式和后台首屏都 READY，系统才允许点火进入主界面。

同时保留 REDMAGIC 9 Pro+ 已实机验证的肩键链：临时激活 REDMAGIC game scene → 读取可信 SAR F7/F8 → Core 语义输入 → 校准结束恢复原场景。

## 首次启动体验

```text
纯黑 Starting Window
  ↓
游戏手机硬件轮廓出现
  ↓
左肩键：轻触唤醒 → 长按上电 → 模块锁定
  ↓
右肩键：轻触唤醒 → 长按上电 → 模块锁定
  ↓
L + R 同时长按 → 控制核心连接
  ↓
ARMED / SYSTEM SYNC
  ↓ 仅当后台 Provisioning READY
整机点火：肩键能量汇入核心 + 物理主马达 + 屏幕共振 + 启动声
  ↓
短暂收黑
  ↓
GAME STAR BOX / SYSTEM ONLINE
  ↓
已经 hydrate 完成的主界面直接出现
```

前台不再使用 `TAP L / HOLD L` 这种开发测试页语言作为视觉主体。肩键被表现为左右控制模块：触发时亮起、长按时能量沿机身汇入中央核心，最终 L+R 作为整机点火手势。

## 两条并行时间轴

### Hardware Awakening

Core 状态机：

`LEFT_TAP -> LEFT_HOLD -> RIGHT_TAP -> RIGHT_HOLD -> BOTH_HOLD -> ARMED -> IGNITING -> COMPLETE`

L+R 长按达标后只进入 `ARMED`，不会自行进入 `IGNITING`。

### First Boot Provisioning

`FirstBootProvisioningCoordinator` 跟踪三个阻塞准备项：

1. `CORE_RUNTIME`：原 BootOrchestrator 的 Core / Capability / REDMAGIC Probe / Session / WebView 阻塞阶段完成；
2. `GAME_CATALOG`：`InstalledGameCatalog.catalogJson()` 在独立后台线程预热完成；
3. `MAIN_SURFACE`：隐藏主 WebView 已加载游戏库、Session、Quick Menu、滚动/手势运行时，并完成至少两帧首屏渲染。

`IgnitionGate = hardwareReady AND provisioningReady`。

只有 Gate open，`BootMainActivity` 才能调用 `ShoulderBootStateMachine.releaseIgnition()`。

## 隐藏首屏预热

主 WebView 在 Hardware Awakening 期间保持 `INVISIBLE`，但提前加载并渲染：

- `scroll-runtime.css`
- `gesture-runtime.js`
- `game-library.js`
- `session-runtime.js`
- `quick-menu-runtime.js`

菜单音乐 `menu-music.js` 仍然只在真实 boot gate 打开后加载，避免与启动音效抢声场。网络、OTA、赛事数据等非首屏工作不得进入 Blocking Gate。

## REDMAGIC 肩键实机链

REDMAGIC 9 Pro+ 实机已经确认：

1. 肩键灯效可以工作，但普通 Android L1/R1 KeyEvent 不一定进入竞界；
2. 肩键底层可表现为 Nubia SAR F7/F8；
3. 仅 Reader 不足，必须先激活 REDMAGIC game scene/SAR 硬件链；
4. 竞界通过独立 Shizuku UserService 保存原 Scene，临时写固定三项 REDMAGIC Global Settings，读取可信 `nubia_tgk_aw_sar` F7/F8，退出后恢复原值；
5. 不设置 `virtual_game_key`，不拉起完整 Game Space，不做输入注入，不永久授予普通 App `WRITE_SECURE_SETTINGS`。

详细安全合同继续见：

- `docs/ENGINEERING_CONSTITUTION_SHOULDER_INPUT_0.4.27.md`
- `app/src/main/java/com/xbu/esportscenter/privileged/SHOULDER_READER.md`

## 物理马达修正

REDMAGIC 9 Pro+ 实机再次暴露了一个重要问题：早期 Hardware Awakening 的 WebAudio 含有 48 Hz 持续 sawtooth hum，以及 58→31 Hz、96→38 Hz、74→46 Hz 等 sub-bass 点火声。用户连接蓝牙耳机后，这些所谓“震动”仍从耳机输出，证明它们属于扬声器音频而不是手机物理马达。

因此本轮明确废止“低频声音模拟触觉”的实现：

- `shoulder-boot.html` 删除持续 hum / humGain / startHum / stopHum；
- 启动音频频率下限提升到 180 Hz；
- 音频只负责可听的机械/电子提示，不再承担任何触觉职责；
- 新增 `HardwareAwakeningMotorDriver`，触觉只允许经 Android `Vibrator` / `VibratorManager` 输出；
- Android 12+ 使用 `VibratorManager.getDefaultVibrator()`；
- Android 13+ 使用 `VibrationAttributes.USAGE_HARDWARE_FEEDBACK`；
- Manifest 固定要求 `android.permission.VIBRATE`；
- REDMAGIC SAR Scene 激活完成后先发一个纯物理短脉冲，作为主马达链路确认；
- 左/右点按、左右长按四级递进、L+R 联合长按与最终点火均使用物理马达波形；
- 不再由 `Settings.System.HAPTIC_FEEDBACK_ENABLED` 作为首次硬件唤醒的总开关；
- 所有马达异常必须记录，不再静默吞掉异常。

稳定马达日志前缀：`[GSB-HAPTIC]`。

关键错误码：

- `GSB-HAPTIC-NO-VIBRATOR-SERVICE`
- `GSB-HAPTIC-NO-PHYSICAL-MOTOR`
- `GSB-HAPTIC-VIBRATE-FAILED`
- `GSB-HAPTIC-CAPABILITY-PROBE-FAILED`
- `GSB-HAPTIC-CANCEL-FAILED`

成功调用会记录 `motor vibrate reason=...`，便于实机区分“音频存在”和“物理马达真正收到调用”。

覆盖安装新增一次性迁移 `hardware_motor_migration_0427_v3`：已测试过早期 Hardware Awakening 的设备会仅再完整运行一次新版物理马达流程，无需清数据；完成后恢复正常 FAST 启动，不会重复重置。

## Core / Adapter 边界

Core 新增：

- `FirstBootProvisioningCoordinator`
- `IgnitionGate`
- `ShoulderBootStateMachine.ARMED`

Core 不引用 Android、WebView、PackageManager、Shizuku、REDMAGIC Settings 或 Vibrator API。

平台层负责：

- 实体肩键输入翻译；
- REDMAGIC SAR 激活/读取；
- 游戏目录后台预热；
- 隐藏 WebView hydrate；
- `HardwareAwakeningMotorDriver` 物理触觉；
- 将语义 READY 状态交给 Core Gate。

## 生命周期

- Activity 切后台时停止当前持续振动；
- 未完成按压不得因 pause/stop 被误判完成；
- 已完成的 `ARMED` 是锁存状态；
- REDMAGIC SAR Reader / Scene 激活按独立 Privileged Adapter 生命周期在后台/退出时恢复；
- Provisioning 线程在 Activity destroy 时停止；
- 首次完成后写入 `shoulder_calibrated_v1`；后续启动可走 FAST hardware wake，但仍必须经过相同 IgnitionGate。

## Preview 前硬门槛

- 红魔 9 Pro+ 不预先进 Game Space 也能直接激活并读取实体左右肩键；
- 蓝牙耳机连接状态下，耳机只能听到启动音，手机触觉必须来自机身物理马达；
- SAR Scene 激活后的纯物理确认脉冲必须能在机身上感觉到，耳机中不得出现对应“震动音”；
- 左右点按/长按顺序正确，长按四级递进来自物理马达；
- L+R 达标只能进入 `ARMED`；
- `CORE_RUNTIME / GAME_CATALOG / MAIN_SURFACE` 任一未完成时不得点火；
- 游戏目录预热不得跑在 UI Thread；
- 主界面第一次可见时游戏卡片、Quick Menu、Session 状态已经完成首屏 hydrate；
- 菜单音乐不得在 Hardware Awakening 期间提前播放；
- Activity pause/stop 不残留持续振动；
- SAR Reader / REDMAGIC Scene 退出后恢复原状态；
- OTA 自更新特权链无回归；
- 不合 main，直到 REDMAGIC 9 Pro+ 实机通过物理马达、体验与 Gate 验收。
