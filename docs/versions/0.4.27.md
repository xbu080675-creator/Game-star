# Game Star Box 0.4.27 / versionCode 40

## 版本目标

0.4.27 将首次启动升级为真正的 **Hardware Awakening / Hardware Playground**：用户不是观看一段开机动画，而是亲手把手机本身玩一遍；与此同时后台完成第一次进入竞界所需的阻塞准备，只有真实硬件序列、Playground 演出和后台首屏都达到允许条件，系统才进入最终点火。

同时保留 REDMAGIC 9 Pro+ 已实机验证的肩键链：临时激活 REDMAGIC game scene → 读取可信 SAR F7/F8 → Core 语义输入 → 校准结束恢复原场景。

## v10：Handheld Home Theme

0.4.27 新增第二套主界面主题，不替换现有大屏 Console 主题：

- `console`：保留原有大幅主机卡片和多层信息布局；
- `handheld`：掌机优先，使用方形软件列、浅层状态栏、底部圆形系统功能带。

## 三条并行条件

### Hardware Awakening Core

Core 肩键状态机：

`LEFT_TAP -> LEFT_HOLD -> RIGHT_TAP -> RIGHT_HOLD -> BOTH_HOLD -> ARMED -> IGNITING -> COMPLETE`

左右单肩校准完成后可以进入 `BOTH_HOLD`，但只有 Core Playground 到达 `FINAL_GRIP` 才允许 L+R 点火计时。若进入 Final 时肩键已被提前按住，必须双侧完整松开后重新按住，才可进入 `ARMED`。

### Hardware Playground Progress

平台无关 Core 顺序：

`SHOULDERS -> MOTION -> GLASS -> MECHANICS -> THERMAL -> FINAL_GRIP -> COMPLETE`

Presentation 只能上报语义阶段完成；乱序或跳关不会推进 Core。

### First Boot Provisioning

`FirstBootProvisioningCoordinator` 跟踪三个阻塞准备项：

1. `CORE_RUNTIME`：原 BootOrchestrator 的 Core / Capability / REDMAGIC Probe / Session / WebView 阻塞阶段完成；
2. `GAME_CATALOG`：`InstalledGameCatalog.catalogJson()` 在独立后台线程预热完成；
3. `MAIN_SURFACE`：隐藏主 WebView 已加载游戏库、主题、Session、Quick Menu、滚动/手势运行时，并完成至少两帧首屏渲染。

Interactive 模式的 `IgnitionGate`：

`hardwareReady && playgroundReady && provisioningReady`

只有 Gate open，`BootMainActivity` 才能调用 `ShoulderBootStateMachine.releaseIgnition()`。FAST 是显式 typed SessionMode，只跳过交互式 Playground，不跳过 Hardware ARMED 与 Provisioning。

## REDMAGIC 肩键实机链

REDMAGIC 9 Pro+ 实机已经确认：

1. 肩键灯效可以工作，但普通 Android L1/R1 KeyEvent 不一定进入竞界；
2. 肩键底层可表现为 Nubia SAR F7/F8；
3. 仅 Reader 不足，必须先激活 REDMAGIC game scene/SAR 硬件链；
4. 竞界通过独立 Shizuku UserService 保存原 Scene，临时写固定三项 REDMAGIC Global Settings，读取可信 `nubia_tgk_aw_sar` F7/F8，退出后恢复原值；
5. 不设置 `virtual_game_key`，不拉起完整 Game Space，不做输入注入，不永久授予普通 App `WRITE_SECURE_SETTINGS`。

## 物理马达修正

早期 Hardware Awakening 曾用低频 WebAudio 模拟“震动”，REDMAGIC 9 Pro+ 连接蓝牙耳机后这些低频仍从耳机输出，证明它们是音频而非物理触觉。该路线已经彻底废止。

当前原则：

- 启动音频只负责可听机械/电子提示；
- 触觉只允许 Android `Vibrator` / `VibratorManager`；
- Android 13+ 使用 `VibrationAttributes.USAGE_HARDWARE_FEEDBACK`；
- REDMAGIC SAR Scene 激活后可用纯物理短脉冲确认主马达链；
- DETENT / RATCHET / LATCH 与 ignition 都使用真实马达波形；
- 蓝牙耳机绝不承载“触觉”。

稳定日志：`[GSB-HAPTIC]` / `[GSB-PLAY-HAPTIC]`。

## Core / Adapter 边界

Core 包含：

- `FirstBootProvisioningCoordinator`
- `IgnitionGate`
- `HardwarePlaygroundProgress`
- `ShoulderBootStateMachine`
- `HardwarePhysicalEvent`

Core 不引用 Android、WebView、PackageManager、Shizuku、REDMAGIC Settings、SensorManager 或 Vibrator API。

平台层负责：

- 实体肩键输入翻译；
- REDMAGIC SAR 激活/读取；
- 游戏目录后台预热；
- 隐藏 WebView hydrate；
- 肩键/点火物理触觉；
- 原生姿态输入；
- 三种物理材质触觉；
- Hardware Playground presentation；
- model-render asset resolution；
- Handheld / Console presentation theme；
- 将语义 READY 状态交给 Core。

## 生命周期

- Activity 切后台时停止当前持续振动和 Motion sensor sampling；
- Haptic Playground adapter 在 pause / finish / destroy 时 cancel；
- 未完成按压不得因 pause/stop 被误判完成；
- REDMAGIC SAR Reader / Scene 激活按独立 Privileged Adapter 生命周期在后台/退出时恢复；
- Provisioning 线程在 Activity destroy 时停止；
- 首次完成后写入 `shoulder_calibrated_v1`；后续启动可走 FAST hardware wake，但仍必须经过 typed IgnitionGate；
- UI 主题使用 WebView 本地偏好，不改变肩键/点火生命周期。
