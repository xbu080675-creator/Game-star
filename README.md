# Game-star

个人电竞中心 Android 原型。

## 当前版本
- 强制横屏
- 沉浸式全屏
- 本地 WebView UI
- Liquid Glass 风格电竞中心首页
- 游戏控制台 / 设备能力交互原型
- 后续接入 Game Detection / Overlay / Device Adapter / Laner

## APK
GitHub Actions 会在 `main` 每次提交后自动构建 Debug APK。

构建完成后进入：

`Actions -> Build Android APK -> 对应运行 -> Artifacts -> Game-star-debug-apk`

下载并解压后得到 `Game-star-debug.apk`，可直接安装测试。
